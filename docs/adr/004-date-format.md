# ADR-004: Использование кастомного формата даты подписки

## Статус
Принято

## Контекст
Дата подписки задаётся в формате "MM-YYYY", что не является стандартным типом PostgreSQL.

## Решение
Использовать кастомное представление даты и обрабатывать его на уровне приложения.

## Причины
- Требования задачи (месяц и год без дня)
- Упрощение API для клиента

## Альтернативы
- Использование DATE с фиксацией дня (например, первое число месяца)

## Почему не выбраны альтернативы
- Может вводить путаницу (лишний день)
- Не соответствует бизнес-логике

## Последствия
+ Соответствие требованиям задачи  
+ Простота API  
- Необходимость дополнительной обработки  
- Потенциальные сложности при агрегациях
