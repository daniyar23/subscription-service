# ADR-002: Использование Gin как HTTP-фреймворка

## Статус
Принято

## Контекст
Необходимо выбрать инструмент для реализации HTTP API на Go.

## Решение
Использовать Gin в качестве HTTP-фреймворка.

## Причины
- Простота использования
- Высокая производительность
- Широкая популярность и сообщество

## Альтернативы
- net/http (стандартная библиотека)

## Почему не выбраны альтернативы
- Требуют больше ручной настройки
- Меньше удобства при разработке REST API

## Последствия
+ Быстрая разработка API  
+ Удобная маршрутизация  
- Меньший контроль по сравнению с net/http
