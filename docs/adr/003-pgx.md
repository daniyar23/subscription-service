# ADR-003: Использование pgx и отказ от ORM

## Статус
Принято

## Контекст
Необходимо реализовать доступ к PostgreSQL базе данных.

## Решение
Использовать pgx (pgxpool.Pool) без ORM.

## Причины
- Полный контроль над SQL-запросами
- Более высокая производительность
- Гибкость при написании сложных запросов
- Показать навыки работы с sql и защитой от sql инъекций

## Альтернативы
- ORM (например GORM)

## Почему не выбраны альтернативы
- Скрывают SQL
- Могут генерировать неоптимальные запросы
- Сложнее контролировать производительность

## Последствия
+ Максимальная гибкость  
+ Прозрачность запросов  
- Больше ручной работы  
- Нужно самостоятельно писать SQL
